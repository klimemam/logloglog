# ユーザー体験の検証項目 / フィードバック

実際にアプリを操作するペルソナエージェントによる検証の記録。
検証項目は「何を確かめるか」、フィードバックは「使ってみて出た問題」。
どちらも検証のたびに追記・更新する。

- 対象: <https://klimemam.github.io/logloglog/>(検証はローカルの本番ビルドで実施)
- 最終更新: 2026-08-04(第1回検証)

## 実施したペルソナ

| # | ペルソナ | 担当領域 |
|---|---|---|
| P1 | 初見の会社員(ランニング・読書) | 初回体験・日々の記録・振り返り |
| P2 | ジム通い(Burnfit経験者) | ワークアウト・種目アイコン・成長記録 |
| P3 | 禁煙したい人(数字好き) | やめる習慣・統計・気づき |
| P4 | 多言語ユーザー兼テスター | 5言語・RTL・極端入力・大量データ・PWA |

いずれも **実装コードを読まずに** 画面だけで操作している(実装を知っていると初見の詰まりを見逃すため)。

## 3. 種目アイコンの評価(P2 + 目視確認)

**結論: 実表示サイズ(32×32 CSS px)ではグリフ単体で種目を判別できない。判別を助けているのは部位ごとの背景色。**

- 名前を隠して当てられたのは 28個中6個程度(スクワット・ショルダープレス・サイドレイズ・ディップス・懸垂・レッグプレス)
- 見分けがつかないペア: ベンチプレス↔ダンベルプレス、懸垂↔ラットプルダウン、ブルガリアンスクワット↔ランジ、アームカール↔ハンマーカール、腕立て伏せ↔プランク、クランチ↔レッグレイズ↔アブローラー
- 単体で意味不明: リアレイズ(×印に見える)、レッグカール(人がおらずベンチだけ)、チェストフライ

実用上はリストが部位で見出しグルーピングされ名前も併記されているため**種目選び自体は成立している**。アイコンは「装飾+色分けによる位置把握」として機能しており、識別子としては機能していない。

改善するなら、器具の特徴(ベンチ/ケーブル/マシン/ダンベル)を1〜2要素だけ大きく描く方向が現実的。

> 補足: 以前のUI評価では同じアイコンに3〜4.5点をつけていたが、それは**拡大画像で評価していた**ため。実サイズでの評価が正しい。

## 4. 良かった点(維持すべき挙動)

- **最初の記録まで2タップ**。説明ゼロで到達できる
- **やめる習慣の誤タップ耐性**。カード9箇所タップで記録0件、確認ダイアログに継続日数リセットを事前明記
- **ワークアウトセッションの復元**。リロード・ブラウザ再起動・タブ移動すべてで復元
- **前回セットの引き継ぎ**。重量・回数・セット数まで
- **大量データ耐性**。1000件で FCP 76ms
- **JavaScriptエラーゼロ**。全ペルソナの全操作を通じて `pageerror` 0件
- **RTLレイアウト**。タブ順・矢印向き・グリッド並びすべて正しく反転

## 5. 検証の実施方法

- ローカルの本番ビルドをプレビュー配信し、Playwright(chromium)で操作
- ペルソナごとに独立したブラウザプロファイル
- **実装コードを読まずに** 画面だけで操作する(実装を知っていると初見の詰まりを見逃す)
- 評価基準は「初見のユーザーが画面だけを見て操作できるか」
