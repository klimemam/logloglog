# ユーザー体験の検証項目 / フィードバック

実際にアプリを操作するペルソナエージェントによる検証の記録。
検証項目は「何を確かめるか」、フィードバックは「使ってみて出た問題」。
どちらも検証のたびに追記・更新する。

- 対象: <https://klimemam.github.io/logloglog/>(検証はローカルの本番ビルドで実施)
- 更新日: 2026-08-04

---

## 1. 検証項目リスト

進行状況の凡例: ⬜ 未検証 / ✅ 問題なし / ⚠️ 要改善 / ❌ 不具合

### A. 初回体験(オンボーディング)

| # | 検証項目 | 状態 |
|---|---|---|
| A1 | 何も説明を読まずに、最初の記録を1件つけられるか | ⬜ |
| A2 | ウェルカム画面の内容が、実際の操作と一致しているか | ⬜ |
| A3 | 習慣ゼロの状態から、習慣追加までの導線が迷わないか | ⬜ |
| A4 | プリセットの並びと内容が、やりたいことに対応しているか | ⬜ |

### B. 日々の記録(最重要導線)

| # | 検証項目 | 状態 |
|---|---|---|
| B1 | アプリを開いて3タップ以内に記録が終わるか | ⬜ |
| B2 | 誤タップで意図しない記録がついたとき、取り消せると気づけるか | ⬜ |
| B3 | 数値つきの記録(距離・ページ数)を既定値以外で入れられるか | ⬜ |
| B4 | 1日に複数回記録したとき、表示が破綻しないか | ⬜ |

### C. 筋トレ / ワークアウトモード

| # | 検証項目 | 状態 |
|---|---|---|
| C1 | 種目ピッカーから目的の種目を見つけられるか(アイコンが助けになるか) | ⬜ |
| C2 | 前回のセットが引き継がれ、修正して記録する流れが自然か | ⬜ |
| C3 | セット完了 → 休憩タイマーの流れが理解できるか | ⬜ |
| C4 | 強度%(推定1RM比)の意味が表示から読み取れるか | ⬜ |
| C5 | 途中で中断・再開できるか(セッションの永続化) | ⬜ |
| C6 | カタログにない種目を自由入力で追加できるか | ⬜ |

### D. やめる習慣(禁煙・禁酒)

| # | 検証項目 | 状態 |
|---|---|---|
| D1 | 「やらないこと」を記録する仕組みだと理解できるか | ⬜ |
| D2 | 継続日数が自動で伸びることが伝わるか | ⬜ |
| D3 | スリップ記録が誤タップで発生しないか | ⬜ |
| D4 | 統計の指標(ベスト継続・週別スリップ)が意味を持つか | ⬜ |

### E. 振り返り(統計・サマリー)

| # | 検証項目 | 状態 |
|---|---|---|
| E1 | デイリーサマリーの濃淡が何を表すか分かるか | ⬜ |
| E2 | 期間切替(4週/12週/半年/1年)が期待どおり効くか | ⬜ |
| E3 | 「気づき」(相関)の文言が誤解を生まないか | ⬜ |
| E4 | レベル・XPが何で増えるか分かるか | ⬜ |

### F. 同期・データ

| # | 検証項目 | 状態 |
|---|---|---|
| F1 | 同期方法の選択肢が理解できるか(Google / メール / GitHub / 引き継ぎコード) | ⬜ |
| F2 | ログイン後にローカルの記録が失われないか | ⬜ |
| F3 | 引き継ぎコード・QRで別端末へ移せるか | ⬜ |
| F4 | エクスポート/インポートが機能するか | ⬜ |

### G. 多言語・アクセシビリティ

| # | 検証項目 | 状態 |
|---|---|---|
| G1 | 英語・中国語・スペイン語で表示が破綻しないか(文字あふれ) | ⬜ |
| G2 | アラビア語でRTLレイアウトが成立しているか | ⬜ |
| G3 | 言語切替後、プリセット習慣名も訳されるか | ⬜ |
| G4 | キーボード操作だけで主要導線を辿れるか | ⬜ |

### H. 堅牢性

| # | 検証項目 | 状態 |
|---|---|---|
| H1 | 記録が数百件あっても表示が重くならないか | ⬜ |
| H2 | 極端な入力(0・負数・巨大値・長い名前)で壊れないか | ⬜ |
| H3 | 画面回転・狭い幅で崩れないか | ⬜ |
| H4 | オフラインで開けるか(PWA) | ⬜ |

## 3. 検証の実施方法

ペルソナエージェントが実際のブラウザでアプリを操作する。

- ローカルの本番ビルドをプレビュー配信し、Playwright(chromium)で操作
- ペルソナごとに独立したブラウザプロファイル(localStorage を共有しない)
- 「初見のユーザーが画面だけを見て操作できるか」を基準に評価する
  (実装を知っている前提の操作はしない)
